# Deep Learning Portfolio

A collection of machine-learning and deep-learning exercises, implementations, and experiments.

## Featured research project

### [GNN Expressivity Lab](gnn_expressivity_lab/README.md)
A research-oriented PyTorch project exploring sparse GCN, GIN, GraphSAGE and GAT models, the 1-dimensional Weisfeiler–Leman (1-WL) test, synthetic feature ablations, and optional TU graph benchmarks with repeated stratified cross-validation.

**Start here:** [Visual guide with diagrams](gnn_expressivity_lab/VISUAL_GUIDE.md) · [Project overview](gnn_expressivity_lab/README.md) · [Supervisor brief](gnn_expressivity_lab/SUPERVISOR_BRIEF.md) · [Presentation narrative](gnn_expressivity_lab/PRESENTATION.md) · [Feature-ablation pilot results](gnn_expressivity_lab/FEATURE_ABLATION_RESULTS.md)

> The GNN project is an exploratory portfolio prototype. Its synthetic results are not a recognised benchmark study or a peer-reviewed research contribution.
