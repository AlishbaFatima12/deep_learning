# Deep Learning Portfolio

A collection of machine-learning and deep-learning exercises, implementations, and experiments.

## Featured research project

### [GNN Expressivity Lab](gnn_expressivity_lab/README.md)
A research-oriented PyTorch implementation exploring Graph Convolutional Networks (GCNs), Graph Isomorphism Networks (GINs), and the 1-dimensional Weisfeiler–Leman (1-WL) test. Includes controlled graph constructions, a reproducible synthetic experiment, unit tests, a supervisor brief, and a presentation.

**Start here:** [Visual guide with diagrams](gnn_expressivity_lab/VISUAL_GUIDE.md) · [Project overview](gnn_expressivity_lab/README.md) · [Supervisor brief](gnn_expressivity_lab/SUPERVISOR_BRIEF.md) · [Presentation narrative](gnn_expressivity_lab/PRESENTATION.md)

> The GNN project is an exploratory portfolio prototype. It is not a peer-reviewed result or a recognised benchmark study.
